# ひらく？とじる？（hiraku-tojiru）

公用文で、ことばを漢字で書くか仮名で書くか（〜していく・して行く、とき・時、及び・および、すばらしい・素晴らしい など）を、短い文の中で選ぶ1日5問の学習ゲーム。正解したら「どの決まりで？」（8つ）も選ぶ。

遊ぶ: <https://satou-aaaaa.github.io/hiraku-tojiru/>

- 中身は、文化審議会建議「公用文作成の考え方」（令和4年1月7日。文化庁 <https://www.bunka.go.jp/seisaku/bunkashingikai/kokugo/hokoku/pdf/93651301_01.pdf>）の「Ⅰ-1 漢字の使い方」とその解説に書いてあることだけです（2026-11-17 に読みました）。
- 答えは公用文（法令・告示・通知など）の書き方です。建議は、広く一般に向けた解説・広報では、漢字で書く語も仮名で書いてよいとしています。ふだんの文章では、どちらも使えることがあります。
